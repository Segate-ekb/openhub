# аудит

Журнал аудита — кто что сделал: одна строка JSON на событие в файле `аудит.log`, её форма,
адреса объектов записи и чтение журнала страницами для экрана. Предметов модуль не знает:
события приходят шиной, имена объектов называют их модули-хозяева через контракт.

## Публичный интерфейс

| Класс | Для чего | Методы |
| --- | --- | --- |
| `ИмяОбъектаАудита` | единственное место, где решается форма адреса объекта, субъекта и принципала записи | `Хаб`, `Система`, `Пул`, `ПулПоИмени`, `Пакет`, `ПакетПоИменам`, `ВерсияПоИменам`, `Версия`, `Тег`, `Пользователь`, `Группа`, `Настройка`, `Провайдер`, `Адрес`, `Зеркало`, `ХранилищеS3`, `ХранилищеФайлами`, `БазаСтран`, `Источник`, `ПоТипу`, `Субъект`, `Неизвестный`, `ЭтоАдресЖурнала` |
| `СобытиеАудита` | нагрузка события для журнала: одна форма полей и деталей на хаб | `Собрать(Кто, Действие, Объект, Субъект, Детали, АдресIP)` |
| `СлужбаАудита` | страница журнала по отбору, новые первыми | `ЗаписиСтраницей(Отбор, Страница, РазмерСтраницы)` |
| `ОтборПоАдресу` | условие отбора по адресу либо сети CIDR | `Условие`, `Подходит` |
| `ФорматЖурналаАудита` | детали записи обратно в поля | `ДеталиПолями` |
| `ИменаОбъектовАудита` (контракт) | предмет называет свои объекты по идентификатору; реализуют `реестр`, `вход`, `права`, собирается массивом | `НазываемыеТипы()`, `ИменаОбъекта(ТипОбъекта, Идентификатор)` |

Производитель события публикует его шиной (`ИздательСобытий`) с нагрузкой `СобытиеАудита.Собрать`;
`СлужбаАудита` подписана на мутирующие события и пишет строку сама.

## Зависимости

Использует: `основа`, `наблюдаемость`, `события`; библиотека `logos`.
Используется: `вход`, `зеркала`, `интерфейс`, `кабинет`, `настройки`, `подписки`, `права`,
`происшествия`, `прокси`, `публикация`, `реестр`.

## Настройки

Своих ключей нет. Файл журнала — `<oshub.storage.root>/аудит.log` (умолчание корня `./data`).

## Где что лежит

| Каталог | Что внутри |
| --- | --- |
| `Классы/` | адрес объекта (`ИмяОбъектаАудита`, контракт `ИменаОбъектовАудита`), нагрузка события, подписчик шины и чтение страницами (`СлужбаАудита`), запись в файл (`ЛетописьАудита`, `АппендерЖурналаАудита`), формат строки, чтение хвоста файла (контракт `ИсточникЖурналаАудита`, реализация `ЧитательЖурналаАудита`), отбор по адресу |

## Инварианты

- Одна запись — одна строка JSON; пишущая и читающая стороны берут формат из `ФорматЖурналаАудита`.
- Файл — единственный приёмник записи: консоль и OTel хаба строк лога `аудит` не печатают
  (`запуск/ЗагрузкаНастроек` называет его журналом со своим приёмником).
- Адрес объекта собирает только `ИмяОбъектаАудита`; запись с адресом другой формы пишется, но с предупреждением в журнал хаба.
- Тип объекта называет ровно один предмет; второй называющий роняет сборку контейнера.
- Журнал не ротируется: читается хвост до 4 МиБ, и страница говорит, что хвост усечён.
- Сбой записи в файл не роняет операцию: событие уходит в журнал хаба ошибкой не чаще раза в минуту.
