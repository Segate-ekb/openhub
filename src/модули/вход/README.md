# вход

Кто пришёл к хабу и чем это доказал: пароль, внешний провайдер, ключ доступа, сессия, вход
из CLI, — и учётная запись от заведения до удаления. Что пришедшему можно, решает `права`;
страницы входа и кабинета рисует `интерфейс`.

## Публичный интерфейс

| `ГеоправилоПровайдера`, `ГейтВходаПоСтране` | правило «провайдер закрыт в странах» и его проверка на запросе | `Правило(…)`, `ЕстьПравила()`, `Обстановка(…)`; `ПровайдерыДляПосетителя(…)`, `Отказов()` |
| `АвтовыдачаПравGitHub` (контракт) | права по репозиториям GitHub после входа провайдером; пустая реализация — у входа, боевая — у `публикация` | `Раздать(ПользовательИдентификатор, ЛогинGitHub, Токен)` |

Контракты чужих модулей, которые реализует вход: `ДопускЗапроса` (`права`) — `ДопускЗапросаКПулу`;
`ЗанятостьИмени` и `ПоследствияУдаленияПула` (`реестр`) — `ЗанятостьИмениЛогином`,
`КлючиУдаляемогоПула`; `ИменаОбъектовАудита` (`аудит`) — `ИменаОбъектовВхода`; `КлючиНастроек`,
`ОписанияСобытий`, `ЗадачаПланировщика` — `КлючиНастроекВхода`, `ОписанияСобытийВхода`,
`ЗадачаЧисткиЗаявокCLI`, `ЗадачаЧисткиПриглашений`. Маршруты `/api/v1` входа (`register`,
`login`, `logout`, `whoami`, `tokens`, `cli/*`) и обвязку каждого запроса (`на-входе/`) winow
собирает сам.

## Зависимости

Использует: `основа`, `данные`, `наблюдаемость`, `настройки`, `события`, `аудит`, `почта`,
`уведомления`, `сеть`, `гео`, `протоколAPI`, `права`, `реестр`; библиотеки `autumn`, `autumn-data`,
`winow`, `pwhash`, `oidc-client`, `oscript-ui` (резолвер слов `ТекстыИнтерфейса`).
Используется: `api`, `интерфейс`, `кабинет`, `публикация`, `состояние`, `подписки`; через контракты —
`права`, `реестр`, `аудит`, `настройки`, `подписки`, `фоновыеЗадания`.

| `oshub.auth.invite.ttl.days` | `7` | срок ссылки установки пароля |

## Где что лежит

| Каталог | Что внутри |
| --- | --- |
| `учётки/` | учётная запись: заведение и поиск, нормализация логина, адрес почты, активность, летопись событий безопасности, следы и удаление; таблица учёток; `СубъектыПрав`, `ЗанятостьИмениЛогином`, `ИменаОбъектовВхода` |
| `паролем/` | вход логином и паролем и его дверь в API (`КонтроллерАутентификации`), политика пароля, лимит попыток, выключатель парольного входа, допуск по подтверждённому адресу, восстановление пароля с письмом; схемы описания API учётки, регистрации и выхода (`…JSON`) |
| `подтверждение-адреса/` | цикл ссылки подтверждения: политика, секрет, заявки и их таблица, адрес страницы, коды отказов, письмо |
| `регистрация/` | режим регистрации, мастер первого запуска, ссылка установки пароля (приглашение и сброс) и её таблица, плановая чистка |
| `сессии/` | серверная сессия: модель, срок со скользящим продлением, служба, таблица |
| `браузер/` | то, что вход держит в браузере человека: куки сессии и транзакции провайдера (`КукаБраузера` — одни атрибуты на обе), токен CSRF, адрес возврата после входа; зовут их экраны и API |
| `ключи/` | ключи доступа: выпуск, отзыв, рамки ключа (`ГейтТокена`), допуск мутаций (`ДопускПринципала`), допуск к пулу (`ДопускЗапросаКПулу`), снятие ключей удаляемого пула; таблицы ключей и привязок; схемы описания API ключа (`…JSON`) |
| `из-cli/` | вход из командной строки: пара кодов, одобрение человеком, опрос, чистка заявок; таблица заявок; схемы описания API заявки, ключа и отказа RFC 8628 (`…JSON`) |
| `провайдером/` | вход через внешнего провайдера: пресеты, конфигурация из базы и окружения, транзакции, личности, автопривязка, правило «закрыт в странах» и оценка его последствий; таблицы провайдеров, личностей и правил |
| `на-входе/` | обвязка каждого запроса: адрес клиента за доверенным прокси, личность запроса, отметка негодного ключа, сбой и неизвестный адрес словами хаба |
| `общее/` | ключи настроек и описания событий входа, сверка секретов, сборка публичной ссылки, слова домена (`СловарьВхода`, `ТекстыВхода`) |

## Инварианты

- Пароли, ключи доступа и одноразовые ссылки хранятся только хешем.
- Уникальность логина и адреса почты держит `вход`, а не база.
- Парольный вход нельзя выключить, пока войти будет некому: это решает `СтражПарольногоВхода`.
- Слова писем и отказов провайдеров — из `СловарьВхода`; словаря экранов домен не читает.
- Заголовки пересылки читаются только с доверенных сетей.
