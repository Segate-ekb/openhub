# почта

Отправка писем хаба по SMTP: гейт «почта настроена», проверка адреса получателя и отказ транспорта
кодом причины, а не исключением. Что писать и кому — решают владельцы писем (`вход`,
`уведомления`); пульт проверки отправки рисует `интерфейс`.

## Публичный интерфейс

| Класс | Для чего | Методы |
| --- | --- | --- |
| `СлужбаПочты` | письмо простым текстом — сразу или фоновым заданием; исключений не отдаёт | `Отправить(Кому, Тема, Текст)`, `ОтправитьВФоне(Кому, Тема, Текст)`, `Настроена()`, `ПричинаНеНастроена()`, `ПричинаАдрес()`, `ПричинаОтказ()` |

Точка расширения — контракт транспорта `ОтправительПисем` (`Отправить(Письмо)`): боевая реализация
`ОтправительПисемSMTP`, в тестах — фейк.

Реализация чужого контракта: `КлючиНастроекПочты` — `КлючиНастроек` (`настройки`).

Только то, что зовут другие модули. Всё остальное — внутреннее.

## Зависимости

Использует: `основа`, `наблюдаемость`, `настройки`, `фоновыеЗадания`; библиотека `InternetMail`.
Используется: `вход`, `уведомления`, `интерфейс`, `настройки`.

## Настройки

| Ключ | Умолчание | Что делает |
| --- | --- | --- |
| `oshub.mail.enabled` | `false` | отправка писем включена |
| `oshub.mail.smtp.host` | пусто | сервер SMTP |
| `oshub.mail.smtp.port` | `587` | порт SMTP |
| `oshub.mail.smtp.user` | пусто | учётка SMTP |
| `oshub.mail.smtp.password` | пусто | пароль SMTP (секрет) |
| `oshub.mail.from` | пусто | адрес отправителя |

## Где что лежит

| Каталог | Что внутри |
| --- | --- |
| `Классы/` | служба почты, параметры из настроек, годность адреса, контракт транспорта и его SMTP-реализация, фоновое задание одного письма, ключи настроек |

## Инварианты

- Почта не настроена (выключена, нет сервера или годного отправителя) — письмо не собирается, ответ — код причины.
- Адрес с разрывом строки или пробелом до транспорта не доходит: подстановки заголовков нет.
- Отказ транспорта — код причины; тема и тело письма в журнал не попадают.
