# события

Внутрипроцессная шина событий хаба: предмет публикует событие, подписчики получают его синхронно,
каждый в изоляции. Здесь же имена типов событий и контракт, которым предмет называет свои события
словами. Перечень событий для людей собирает `подписки` (`КаталогСобытий`), журнал аудита пишет `аудит`.

## Публичный интерфейс

| Класс | Для чего | Методы |
| --- | --- | --- |
| `ИздательСобытий` | шина: подписка на тип, публикация, счёт уроненных доставок | `Подписать(ТипСобытия, Подписчик)`, `Опубликовать(ТипСобытия, Данные, Момент)`, `ПропущенныхДоставок()`, `КоличествоПодписчиков(ТипСобытия)`, имена типов `Тип<Событие>()` — `ТипВерсияОпубликована`, `ТипПулУдалён`, `ТипПраваИзменены` и другие |
| `ОписанияСобытий` (контракт) | события предмета словами; реализуют предметы как `ОписанияСобытий<Предмет>` | `Объявления()` |
| `ОбъявленияСобытий` | запись объявлений предмета; создаётся `Новый` | `ОбъявитьПодписочное`, `ОбъявитьВнутреннее`, `События` |

Подписчик — любой объект с методом `ОбработатьСобытие(Событие)`; событие — структура `Тип`,
`Когда`, `Данные`.

Только то, что зовут другие модули. Всё остальное — внутреннее.

## Зависимости

Использует: только библиотеку `autumn-logos` (журнал).
Используется: всеми модулями, которые публикуют или слушают события: `аудит`, `настройки`,
`статистика`, `реестр`, `права`, `вход`, `прокси`, `зеркала`, `публикация`, `подписки`,
`кабинет`, `состояние`, `api`.

## Где что лежит

| Каталог | Что внутри |
| --- | --- |
| `Классы/` | шина `ИздательСобытий`, контракт `ОписанияСобытий`, помощник `ОбъявленияСобытий` |

## Инварианты

- Публикация не бросает: сбой подписчика не роняет ни соседей, ни того, кто публикует.
- Каждая уроненная доставка считается; ненулевой счёт — пропущенные записи журнала аудита.
- Метод контракта `ОписанияСобытий` бросает: реализацию даёт предмет.
- У подписочного события обязателен латинский код — строчные слова через точку
  (`version.published`): им событие называется в заголовке вебхука. Внутреннее событие несёт код,
  только если всё же уходит подписке (проба). Объявление без кода или с негодным кодом бросает.
