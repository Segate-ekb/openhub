# происшествия

Память хаба о работе, которую он не сделал: пропущенная зеркалом версия, лежащее хранилище,
молчащий источник, база стран без обновления. Модуль отвечает, над чем, что именно, почему
и когда в последний раз; что с этим делать, решают подсистемы и экраны.

## Публичный интерфейс

| Класс | Для чего | Методы |
| --- | --- | --- |
| `ЛетописьПроисшествий` | запись со свёрткой повторов, снятие, начало обхода; наружу не бросает | `Записать(Подсистема, Объект, Предмет, Код, Причина, Прогон, Секрет)`, `Снять`, `НачатьПрогон`, `ПределПричины` |
| `ЧитательПроисшествий` | снимки для экранов и API, последние сверху; лежащая база — исключение | `ПроисшествияОбъекта`, `ПроисшествияОбъектов`, `ЕстьПроисшествия`, `ЧислоПроисшествий` |
| `ОбъектыПроисшествий` | адрес объекта: форма журнала аудита плюс обезличивание | `Зеркало`, `ХранилищеS3`, `ХранилищеФайлами`, `БазаСтран`, `Источник` |
| `КодыПроисшествий` | общий словарь кодов всех подсистем, «пройдёт само» и «исход неясен» | `Подсистемы`, `Все`, `Устранимо`, `ИсходНеясен`, `Прочее` |
| `КодыПроисшествийПодсистемы` (контракт) | коды подсистемы; реализуют `гео`, `зеркала`, `прокси`, `хранилище`, собирается массивом | `Объявления()` |
| `ОбъявленияКодовПроисшествий` | объявления, которыми подсистема отвечает на контракт | `Объявить`, `ОбъявитьНеясным`, `Объявленный`, `Подсистема`, `Коды` |

Подсистема объявляет коды о себе:

```bsl
&Прозвище("КодыПроисшествийПодсистемы")
&Желудь
Процедура ПриСозданииОбъекта() Экспорт
	Коды = Новый ОбъявленияКодовПроисшествий("гео");
	Коды.Объявить("geo_db_missing", Ложь);         // само не пройдёт
	Коды.Объявить("geo_db_update_failed", Истина); // снимет следующий заход
КонецПроцедуры

Функция БазыСтранНет() Экспорт
	Возврат Коды.Объявленный("geo_db_missing");
КонецФункции
```

## Зависимости

Использует: `основа`, `данные`, `наблюдаемость`, `настройки`, `аудит` (`ИмяОбъектаАудита`); библиотека `autumn-data`.
Используется: `гео`, `зеркала`, `прокси`, `хранилище`, `интерфейс`.

## Настройки

| Ключ | Умолчание | Что делает |
| --- | --- | --- |
| `oshub.incidents.max_per_object` | `50` | потолок записей на пару «подсистема + объект»; последний слот — сводка «прочее» |
| `oshub.incidents.ttl.sec` | `1209600` | сколько живёт запись, которой никто не касался |
| `oshub.jobs.incidents_gc_interval_sec` | `3600` | интервал задачи чистки устаревших |

## Где что лежит

| Каталог | Что внутри |
| --- | --- |
| `Классы/` | летопись и читатель, адрес объекта, словарь кодов с контрактом и объявлениями, таблица (`Происшествие`, `ХранилищеПроисшествий`), задача чистки, ключи настроек |

## Инварианты

- Ключ записи — подсистема, объект, предмет, код и прогон; подсистема входит в ключ везде: объект бывает общим у двух подсистем.
- Свёртка, снятие и уборка идут под одним процессным замком; уникальность ключа держит свёртка, а не база.
- Переполнение не молчит: сверх потолка счёт идёт в сводку «прочее».
- Секрет, названный параметром, и учётные данные адресов в причину не попадают; причина обрезается до 500 символов.
- Необъявленный код — исключение в `Объявленный`; незнакомый код читается как «исход неясен».
