# поиск

Поиск пакетов для каталога и `GET /api/v1/search`: выдача ограничена пулами, которые видит автор
запроса, и ранжируется по релевантности, популярности, свежести и имени. Право на чтение пула
решает `права`, пакеты отдаёт `реестр`, число скачиваний — `статистика`.

## Публичный интерфейс

| Класс | Для чего | Методы |
| --- | --- | --- |
| `СлужбаПоиска` | ранжированный поиск пакетов со страницами | `НайтиПакеты(Запрос, Страница, РазмерСтраницы, Принципал)` |
| `ВидимостьПулов` | решение видимости пулов на один запрос | `Решение(Принципал)`, `ПулВиден(Решение, ПулИдентификатор)` |

Только то, что зовут другие модули. Всё остальное — внутреннее.

## Зависимости

Использует: `основа`, `права`, `реестр`, `статистика`.
Используется: `api`, `интерфейс`.

## Где что лежит

| Каталог | Что внутри |
| --- | --- |
| `Классы/` | `СлужбаПоиска` — отбор и ранжирование; `ВидимостьПулов` — какие пулы можно называть запросу |

## Инварианты

- Пакет невидимого пула, в том числе пакет без пула, в выдачу не попадает.
- Скрытый пакет в выдачу не попадает.
- Если по подстроке не нашлось ничего, отбор повторяется нечётко по имени.
- Сбой статистики не роняет поиск: популярность у всех становится нулевой.

## Тесты

`scripts/тесты.sh поиск` — наборы `tests/поиск/`; `--e2e` добавляет `tests/e2e/поиск/`.
