# сеть

Исходящий HTTP хаба поверх 1connector: одна дверь для запросов наружу, ожидание чужого сервера
и суждение о том, ведёт ли адрес в свою сеть. Куда ходить и что делать с ответом, решает
вызывающий.

## Публичный интерфейс

| Класс | Для чего | Методы |
| --- | --- | --- |
| `КлиентHTTP` (прозвище `ТранспортHTTP`) | GET и POST без ретраев; код ответа как есть, переходы по Location — только по просьбе | `Получить(URL, Заголовки, ТаймаутСек, ПроверятьSSL, РазрешитьПеренаправление)`, `Отправить(URL, Тело, Заголовки, ТаймаутСек, ПроверятьSSL)`, `ИмяАгента()` |
| `СессияИсходящегоHTTP` | сессия 1connector для библиотек, которые ходят в сеть сами (oidc-client) | `ВызватьМетод(Метод, URL, ДополнительныеПараметры)` |
| `ТаймаутыHTTP` | ожидание похода в апстрим (настраивается) и служебного запроса (нет) | `ТаймаутАпстрима(Настройки)`, `КлючТаймаутаАпстрима()`, `ТаймаутСлужебногоЗапроса()` |
| `СвояСеть` | ведёт ли хост в петлю, частную или зарезервированную сеть — по записи, без резолва | `Вердикт(Хост)`, `ЭтоСвояСеть(Хост)`, `ЭтоПетля(Хост)`, `Коды()` |

## Зависимости

Использует: `основа`; библиотека `1connector`.
Используется: `вход`, `гео`, `зеркала`, `подписки`, `права`, `прокси`, `публикация`.

## Настройки

| Ключ | Умолчание | Что делает |
| --- | --- | --- |
| `oshub.proxy.timeout.sec` | 20 (ключ объявляет `прокси`) | ожидание похода в апстрим, читается на каждом запросе |

## Где что лежит

| Каталог | Что внутри |
| --- | --- |
| `Классы/` | клиент и его коннектор к 1connector, сессия, таймауты, своя сеть |

## Инварианты

- Сетевой сбой и таймаут клиент бросает исключением; код ответа — любой, в том числе 304 и 404.
- Список своих и зарезервированных сетей один на хаб и живёт в `СвояСеть`.
