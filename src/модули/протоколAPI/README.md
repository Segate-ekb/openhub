# протоколAPI

Соглашения машинного API `/api/v1`, которым следует всякий, кто этот протокол говорит: как читается
присланное клиентом, как маршрут отказывает лишнему хвосту пути и чужому методу, как список режется
на страницы и где лежит артефакт для `opm`. Маршрутов здесь нет — они в `api` и `вход`.

## Публичный интерфейс

| Класс | Для чего | Методы |
| --- | --- | --- |
| `ЗапросAPI` | тело запроса, его поля и заголовки, терпимое чтение флага | `РазобратьТело(…)`, `Поле(…)`, `Присланное(…)`, `ПрисланныйФлаг(…)`, `ВБулево(…)`, `СнятиеТокенаИсточника(…)`, `Заголовок(…)` |
| `МаршрутAPI` | пролог маршрута: ответ без сессионной куки, 404 на лишний хвост пути, 405 с `Allow` на чужой метод | `Начать(…)`, `НачатьЧтение(…)`, `НачатьДействие(…)`, `ЛишнийХвостПути(…)`, `МетодНеРазрешён(…)`, `СнятьКуку(…)` |
| `СтраницыAPI` | страница списка: номер и размер из query, потолок выдачи, срез и конверт `items`/`page`/`pageSize`/`total`/`has_more` | `РазметкаЛистания(…)`, `РазметкаЦеликом(…)`, `РазметкаОтСервиса(…)`, `Перечень(…)`, `Срез(…)`, `Конверт(…)`, `Размер(…)` |
| `АдресаВыдачи` | канонический адрес артефакта — тот же, что читает `opm` | `ТочнаяВерсия(…)`, `ПоТегу(…)`, `ОсновнойТег(…)` |

## Зависимости

Использует: `основа`, `настройки` (необязательно — без неё страницы работают на умолчаниях кода).
Используется: `api`, `вход` (список ключей), `интерфейс` (кнопка скачивания).

## Настройки

| Ключ | Умолчание | Что делает |
| --- | --- | --- |
| `oshub.api.page_size` | `20` | размер страницы у ручек, которые листают, когда клиент его не назвал |
| `oshub.api.page_max` | `200` | потолок выдачи: больше элементов в одном ответе не бывает |

## Где что лежит

| Каталог | Что внутри |
| --- | --- |
| `Классы/` | модуль плоский: четыре класса протокола и объявление ключей страниц (`КлючиНастроекAPI`) |

## Инварианты

- Ответ API не ставит сессионную куку.
- Усечённый список не молчит: `has_more` говорит, что за потолком выдачи осталось ещё.
- Адрес артефакта один на хаб и `opm`: экран и выдача берут его у `АдресаВыдачи`.
