# наблюдаемость

То, что нужно любому модулю на самом низу: журнал хаба — уровни, способы вывода и обезличивание
строки на выходе — и признак готовности, который закрывают стартовые задачи. Приборы и пробы
работающего хаба живут в `состояние`.

## Публичный интерфейс

| Класс | Для чего | Методы |
| --- | --- | --- |
| `ОбезличиваниеЖурнала` | значение, безопасное для журнала: адрес без запроса и учётных данных, адрес клиента без хозяина, почта без ящика, секрет фактом наличия; строка журнала без ящиков почты | `Адрес`, `АдресКлиента`, `Почта`, `ПочтаВТексте`, `Секрет`, `Событие` |
| `ГотовностьХаба` | готов ли хаб принимать трафик: стартовые задачи заявляют себя и отмечаются выполненными | `ЗаявитьЗадачу`, `ОтметитьЗадачуВыполненной`, `ОтметитьСтартЗавершённым`, `Готов`, `НезавершённыеЗадачи`, `МоментГотовности`, `Состояние` |
| `УровниЖурнала` | узлы `logos.logger` и `logos.appender` из уровней корневого журнала и компонентов | `Связка`, `СтрокаПроходит`, `Замечания` |
| `ВыводЛогаВКонсольХаба`, `ВыводЛогаВOTelХаба` | способы вывода logos: консоль по уровню своего лога и мост OTel — оба через обезличивание | контракт способа вывода logos |

## Зависимости

Использует: `основа`; библиотеки `logos`, `opentelemetry`.
Используется: `аудит`, `вход`, `запуск`, `зеркала`, `подписки`, `почта`, `происшествия`, `прокси`, `публикация`,
`состояние`, `статистика`, `фоновыеЗадания`; способы вывода подключает `src/main.os`.

## Где что лежит

| Каталог | Что внутри |
| --- | --- |
| `Классы/журнал/` | уровни, способы вывода, обезличивание |
| `Классы/пробы/` | признак готовности |

## Инварианты

- Строка журнала уходит наружу только через `ОбезличиваниеЖурнала.Событие`.
- Способы вывода объявлены самым подробным из запрошенных уровней; отбор по уровню своего лога — в `УровниЖурнала.СтрокаПроходит`.

## Тесты

`scripts/тесты.sh наблюдаемость` — наборы `tests/наблюдаемость/`; `--e2e` добавляет живые наборы
`tests/e2e/наблюдаемость/` (телеметрия против OTLP-приёмника).
