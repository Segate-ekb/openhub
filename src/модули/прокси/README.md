# прокси

Источники пула (апстримы) и выдача через них: поход к чужому хабу, память о его живости, перечни
версий источников, скачивание с кэшированием в пул и уборка привезённого. Резолвер выдачи, уборка кэша
и наблюдатель коллизий спрашивают реестр о своих пакетах, но их предмет — когда и что брать у источника,
поэтому они здесь. Плановая репликация чужого хаба — модуль `зеркала`; своих экранов и ручек API нет.

## Публичный интерфейс

| Класс | Для чего | Методы |
| --- | --- | --- |
| `РезолверВыдачи` | выдача пула: свои версии, источники по порядку, кэш и индекс пула, 404 | `РазрешитьФайл(ИмяПула, ИмяКанала, ИмяПакета, ЗапросФайла)`, `ОбъяснитьОтказ(ИмяПула, ИмяКанала, ИмяПакета, ЗапросФайла)`, `ПотокСодержимого(Разрешение)`, `ИменаПула(ИмяПула)` |
| `ОбъединённыйНаборВерсий` | выбор версии среди своих и названных источниками: побеждает самая поздняя | `ВыбратьПоСпецификации(Пул, Источники, Пакет, ИмяПакета, Спецификация, СвояВерсия)`, `ВыбратьТегом(Пул, Источники, Пакет, ИмяПакета, ИмяТега, СвояВерсия)` |
| `КлиентАпстрима` | один поход к источнику по контракту opm: заголовки, переходы, таймаут; недоступность — код 0 | `ПолучитьТекст(БазовыйURL, ОтносительныйПуть, УсловныйETag, Токен)`, `СкачатьВФайл(БазовыйURL, ОтносительныйПуть, ПутьФайла, УсловныйETag, Токен, УсловнаяОтметка)` |
| `ПробникИсточника` | пробное подключение к источнику | `Проверить(БазовыйURL, Токен)`, `ТребоватьПодключение(БазовыйURL, Токен)`, `ПробаВключена()` |
| `СекретИсточника` | правило токена источника: приём ввода, предъявление, отпечаток | `Задан(Токен)`, `ИзИсточника(Источник)`, `ДляЖурнала(Токен)`, `ПринятьВвод(Введённое, Прежний)`, `Предъявить(Заголовки, Токен)`, `Отпечаток(Токен)`, `ЭтоОтказДоступа(Код)`, `Отозвать(Заголовки)` |
| `СтражАпстримов` | память процесса о живости адреса и об отказе доступа | `Допустим(Апстрим)`, `ПричинаОтказа(Апстрим)`, `Пропустить(Апстрим)`, `Состояние(Апстрим)`, `ОтметитьЖивым(Адрес, Токен)`, `ОтметитьЛежащим(Адрес, Причина, Токен)`, `ОтметитьНеПустившим(Адрес, Причина, Токен)`, `Забыть()` |
| `СостояниеИсточников` | состояние источника словом для экрана и API | `ПоИсточникам(Источники)`, `СУчётомТумблера(Состояние, Включён)`, `Жив()`, `Лежит()`, `НеПустил()`, `НеПроверялся()`, `Выключен()` |
| `РазборВерсийПакета` | версии пакета со страницы пакета источника | `Версии(Разметка, ИмяПакета)` |

Только то, что зовут другие модули. Всё остальное — внутреннее.

Реализует контракты: `ЗаведениеИсточника` (`ЗаведениеИсточникаСПробой`: `ПринятьДоступ`, `ПринятьТокен`),
`ЗадачаПланировщика` (`ЗадачаСбораКэшаПрокси`, задача `gc-кэша-прокси`), `КлючиНастроек` (`КлючиНастроекПрокси`),
`КодыПроисшествийПодсистемы` (`КодыПроисшествийИсточника`, подсистема `источник`: `upstream_down`, `upstream_denied`),
`ОписанияСобытий` (`ОписанияСобытийПрокси`: коллизия имени с апстримом).

## Зависимости

Использует: `основа`, `сеть`, `наблюдаемость`, `настройки`, `происшествия`, `события`, `аудит`, `реестр`,
`хранилище`, `фоновыеЗадания` (контракт задачи); библиотеки `ospx-tools`, `url`, `autumn-opentelemetry`.
Используется: `api`, `интерфейс`, `зеркала`; `реестр` — через контракт `ЗаведениеИсточника`.

## Настройки

| Ключ | Умолчание | Что делает |
| --- | --- | --- |
| `oshub.proxy.offline` | `false` | к источникам не ходить: отвечать кэшем и индексом пула |
| `oshub.proxy.timeout.sec` | `20` | сколько хаб ждёт источник |
| `oshub.proxy.negative.ttl.sec` | `60` | сколько помнится «у источника этого нет» |
| `oshub.proxy.upstream.recheck.ttl.sec` | `300` | сколько живёт отметка стража о живости; `0` — не помнить |
| `oshub.proxy.max_redirects` | `5` | потолок переходов по `Location` |
| `oshub.upstream.probe.enabled` | `true` | заводить источник только после удачной пробы |
| `oshub.jobs.proxy_gc_interval_sec` | `3600` | период уборки привезённого (`bootstrap`) |

## Где что лежит

| Каталог | Что внутри |
| --- | --- |
| `источники/` | поход наружу, проба, токен, адрес записи, страж живости и его письменный двойник (`ЛетописьИсточников`), правка их карт копией (`ПравкаКартыКопией`), состояние словом, причина молчания фразой, заведение источника пробой, коды происшествий |
| `версии-источников/` | какие версии знает один источник, разбор страницы пакета, объединённый набор своих и чужих версий |
| `выдача/` | резолвер выдачи пула, скачивание с источника в пул с ленивой индексацией (`СервисПрокси`), сверка тела с ETag |
| `кэш/` | кэш изменяемых ресурсов источника в памяти, уборка привезённого до квоты пула и её плановая задача |
| `коллизии-имён/` | наблюдатель публикаций: своё имя совпало с именем у источника пула; описание события |
| `общее/` | объявление ключей настроек |

## Инварианты

- Причину молчания нормализует граница стража: в память, в базу и на экран уходит одна фраза.
- Живость — свойство адреса без учёта регистра, «не пустил» — пары «адрес + отпечаток токена»; значение токена в памяти не живёт.
- Карты стража и летописи правятся копией: их пишут и обход здоровья, и потоки выдачи.
- Письменный двойник пишет на смене состояния и не чаще раза в срок; удачный запрос к живому источнику в базу не ходит.
- Уборка вытесняет только версии с провенансом «апстрим»; своя публикация не трогается.
