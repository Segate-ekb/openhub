# данные

Техника доступа к базе, общая для хранилищ всех предметов: агрегаты одним запросом с выборкой
в памяти там, где бэкенд SQL не исполняет, снятие строк при уборке, таблица «ключ → строка»
и снимок строки для кэша. Таблиц модуль не держит — сущности и `Хранилище*` живут у хозяев.

## Публичный интерфейс

| Класс | Для чего | Методы |
| --- | --- | --- |
| `АгрегатыБазы` | счёт, сумма, наличие и разрезы по ключу: запросом к базе либо выборкой в памяти, одна цифра на обеих дорогах | `Количество(Хранилище, Опции)`, `Есть(Хранилище, Опции)`, `Сумма(Хранилище, ИмяПоля, Опции)`, `КоличествоПоКлючу(Хранилище, ИмяПоляКлюча, Опции)`, `СуммаПоКлючу(Хранилище, ИмяПоляКлюча, ИмяПоляСуммы, Опции)`, `БазаСчитает(Хранилище)` |
| `СнятиеСтрок` | снимает пачку строк и считает снятые | `Снять(Строки)`, `СнятьЧерез(Хранилище, Строки)` |
| `ТаблицаПоКлючу` | строка по каноничному ключу поверх хранилища с заглушками `ПолучитьПоКлючРавноПервые`, `ПолучитьУпорядочитьПоКлючВозр` | `НайтиЗапись(Ключ)`, `НайтиИлиЗавести(Ключ)`, `Удалить(Ключ)`, `Все()` |
| `ФормаСнимка` | неизменяемый снимок строки сущности для кэша в памяти | `Снимок(Запись)`, `Снимки(Записи)` |

## Зависимости

Использует: `основа`; библиотеки `autumn-data`, `entity`, `errors`.
Используется: `вход`, `зеркала`, `настройки`, `подписки`, `права`, `происшествия`, `публикация`, `реестр`,
`статистика`, `уведомления`.

## Где что лежит

| Каталог | Что внутри |
| --- | --- |
| `Классы/` | агрегаты и их текст запроса (`ТекстАгрегата`, `ОписаниеСущности`), снятие строк, таблица по ключу, снимок |

## Инварианты

- Текст агрегата собирается из имён модели сущности, значения отбора подставляются одной дверью.
- У каждого агрегата есть дорога в памяти; её цифра совпадает с цифрой базы.
- Постраничный отбор и суммирование не числового поля агрегат отвергает на обеих дорогах одинаково.
