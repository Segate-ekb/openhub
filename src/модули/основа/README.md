# основа

Примитивы, на которых стоит весь хаб: разбор адресов и заголовков, приведение внешних значений,
текст ошибки и ответа, JSON, хеши. Предметов хаба модуль не знает — ни пакетов, ни учёток,
ни настроек; появилось знание — класс уезжает к хозяину.

## Публичный интерфейс

Все классы модуля зовут соседи; большинство создаётся «Новым», без контейнера.

**Адреса и сеть**

| Класс | Для чего | Методы |
| --- | --- | --- |
| `РазборАдреса` | схема, узел, путь и каноничная запись адреса одним разбором | `СхемаИУзел`, `Каноничный`, `Узел`, `ДоПути`, `БезСхемы`, `ПрефиксСхемы`, `БезХвостовыхСлешей`, `БезХвостовогоСегмента`, `БезЗапросаИЯкоря`, `ПозицияПути`, `ДоСимвола`, `ЗаканчиваетсяНа`, `НайтиУправляющий` |
| `ФормаАдреса` | первый вопрос, на который внешний адрес не ответил: пусто, управляющий символ, схема, userinfo, хост | `Разобрать(Адрес, ДопустимыеСхемы)`, `Коды()` |
| `ПараметрыСсылки` | параметр запроса на адресе, закодированный по RFC 3986 | `Установить`, `Добавить` |
| `КанонIP` | строка → IP-адрес или сеть; каноничная запись адреса | `Разобрать`, `Адрес`, `Строкой`, `ВложенныйIPv4`, `БезСкобокИПорта`, `Сеть`, `ВСети`, `Список` |

**HTTP-ответ машинной двери**

| Класс | Для чего | Методы |
| --- | --- | --- |
| `ОтветыAPI` | JSON-ответ и конверт ошибки `{error:{code,message,details}}`, разбор тела JSON и формы | `JSON`, `Ошибка`, `Сбой`, `РазобратьТело`, `Поле`, `Список`, `БезСессионнойКуки` |
| `ЗаголовкиHTTP` | заголовок по имени без учёта регистра | `Значение`, `Текст`, `КлючПоИмени`, `Без` |
| `ЗаголовкиКэша` | `Cache-Control`, `Referrer-Policy`, `ETag` и ответ 304 | `ОтдатьСтраницу`, `ЗакрытьСтраницу`, `НеКэшировать`, `КэшСтраницы`, `НеизменяемыйКэш`, `КэшИзменяемогоАдреса`, `ПриватныйКэш`, `СрокСтраницы`, `ПолитикаПерехода`, `Метка`, `МеткаСодержимого`, `ТелоМетки`, `СовпадаетETag` |
| `МетодыHTTP` | сравнение метода запроса без учёта регистра | `ЭтоМетод` |
| `ЗаписьФормы` | пары тела `application/x-www-form-urlencoded` | `Пары` |
| `МоментISO` | момент строкой ISO 8601 UTC | `Строкой` |

**Сбой запроса**

| Класс | Для чего | Методы |
| --- | --- | --- |
| `ТекстОшибки` | сбой одной строкой журнала, полным отчётом и фразой человеку | `Причина`, `МашинныйКод`, `ПодробныйОтчёт`, `ДляЧеловека`, `Фраза`, `Кратко`, `Однострочно`, `БезСлужебного`, `БезСекрета`, `Маска` |
| `ПричинаСбояЗапроса` | код, статус и `Retry-After` для необработанного сбоя; отказ базы — 503 | `ПоСбою`, `ПоТексту`, `ЭтоОтказБазы`, `ЭтоОтказБазыПоТексту`, `КодОтказаБазы` |
| `СбойХабаСловами` (контракт) | фраза и страница сбоя; реализует `интерфейс` | `Фраза(КодСбоя)`, `Страница(КодСбоя, Статус, КодЗапроса, КукиЗапроса)` |
| `НеизвестныйАдресСловами` (контракт) | фраза и страница «адрес не найден»; реализует `интерфейс` | `Фраза()`, `Страница(ЗаголовкиЗапроса, КукиЗапроса, ПутьЗапроса)` |

**Внешние значения и текст**

| Класс | Для чего | Методы |
| --- | --- | --- |
| `ПриведениеЧисел` | число из внешнего значения: терпимо, строго, со знаком | `ЧислоИлиНоль`, `ЧислоИлиДефолт`, `ЦелоеИлиНеопределено`, `ЦелоеСоЗнакомИлиНеопределено`, `ЦелоеСтрогоИлиНоль`, `ЦелаяЧасть`, `НеотрицательноеЦелое`, `Текстом` |
| `ПриведениеФлагов` | булево из внешнего значения — по двери источника | `ФлагИстина`, `ФлагТолькоTrue`, `ФлажокФормы`, `ФлагТрёхзначный`, `ФлагОкружения` |
| `ЧтениеПолей` | поле Структуры или Соответствия со значением по умолчанию | `Поле` |
| `КанонСтроки` | каноничная запись ключа: без краёв, в нижнем регистре | `Канон` |
| `СписокЧерезЗапятую` | элементы списка в одной колонке | `Разобрать`, `Содержит` |
| `КонтрольСимволов` | управляющие символы, разрывы Юникода, очистка метки | `ПервыйУправляющийИлиПробел`, `ЕстьУправляющий`, `ЕстьУправляющийПробелИлиРазрыв`, `ПервыйВнеПечатнойЛатиницы`, `Очистить`, `ИмяКода`, `ЭтоУправляющийC0`, `ЭтоDEL`, `ЭтоРазрывЮникода`, `ЭтоПечатнаяЛатиница` |
| `ТекстJSON` | значение в JSON: в строку, с переносами, с отступами | `ОднойСтрокой`, `СПереносами`, `СОтступами` |
| `ОбрезаниеТекста` | текст с многоточием, перечень со свёрнутым хвостом | `СМноготочием`, `ПереченьСОстатком` |
| `ОбъёмТекстом` | байты человеку: «430,2 МБ» | `Представление` |
| `Хеш` | sha256 строки, данных и файла; короткий отпечаток | `ОтСтроки`, `ОтДанных`, `ОтФайла`, `Отпечаток`, `ДлинаОтпечатка` |
| `ПоискПоКоллекции` | отбор коллекции по подстроке с ранжированием, нечётко при промахе | `Отобрать`, `ОценкаРелевантности`, `ОтобратьНечётко` |

**Остальное**

| Класс | Для чего | Методы |
| --- | --- | --- |
| `Вердикт` | ответ «получилось или нет и почему» одной формой | `Успех`, `Отказ`, `УспехСловами`, `ОтказСловами`, `УспехСКодом`, `ОтказСКодом`, `Поверх` |
| `ВнедрённыеЖелуди` | первый желудь из необязательного внедрения | `ПервыйИз` |
| `СекретИзФайла` | секрет значением либо файлом | `Секрет` |
| `ТихаяУборка` | временный путь и его уборка без исключений | `ВременныйПуть`, `УдалитьФайл` |

## Зависимости

Использует: только библиотеки `url`, `ip`, `errors`, `fzy`.
Используется: всеми модулями хаба.

## Где что лежит

| Каталог | Что внутри |
| --- | --- |
| `Классы/` | все классы модуля, без подкаталогов |

## Инварианты

- Модуль не зовёт ни одного другого модуля хаба.
- Методы контрактов `СбойХабаСловами` и `НеизвестныйАдресСловами` бросают: реализацию даёт `интерфейс`.
