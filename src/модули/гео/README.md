# гео

Из какой страны пришёл запрос: хаб отвечает сам — встроенной базой диапазонов DB-IP Lite Country
и заголовком доверенного обратного прокси — и в момент запроса никуда не ходит. Что делать со страной,
модуль не решает: правила по стране и отказ посетителю живут во `вход`. База — под CC BY 4.0: страницы,
которые пользуются результатом, печатают `IP Geolocation by DB-IP` со ссылкой на `https://db-ip.com`.

## Публичный интерфейс

| Класс | Для чего | Методы |
| --- | --- | --- |
| `ОпределительСтраны` | страна запроса тремя исходами — известна, не из наблюдаемых, неизвестна — с источником и причиной словами; какие страны наблюдать; состояние базы | `Определить(АдресКлиента, КодОтПрокси)`, `ОпределитьПоЗапросу(АдресКлиента, Заголовки)`, `Исходы`, `ИсточникБазы`, `ИсточникПрокси`, `ИмяЗаголовка`, `ПорядокИсточников`, `НаблюдатьСтраны`, `НаблюдаемыеСтраны`, `ЗаказанныеСтраны`, `СостояниеБазы` |
| `СправочникСтран` | коды ISO 3166-1 alpha-2 для всего хаба | `Канон`, `ЭтоКод`, `Все`, `Количество` |

```bsl
Определитель.НаблюдатьСтраны(Страны);  // правила называют страны — под них строится индекс

Вердикт = Определитель.ОпределитьПоЗапросу(Запрос.АдресУдаленногоУзла, Запрос.Заголовки);
Если Вердикт.Исход = Определитель.Исходы().Известна Тогда
	// Вердикт.Страна — код, Вердикт.Источник — «база» либо «прокси»
КонецЕсли;
```

## Зависимости

Использует: `основа`, `сеть` (`СвояСеть`, `ТранспортHTTP`), `фоновыеЗадания`, `настройки`, `происшествия`;
библиотеки `ip`, `compressor`.
Используется: `вход` (гейт и геоправило провайдера, доверие заголовку страны, заказ наблюдаемых стран),
`интерфейс` (окно «Страны и доступ», атрибуция базы, страница `/whoami`).

## Настройки

| Ключ | Умолчание | Что делает |
| --- | --- | --- |
| `oshub.geo.db_path` | пусто | путь к файлу базы; пусто — `<oshub.storage.root>/гео/dbip-country-lite.csv` |
| `oshub.geo.header` | `CF-IPCountry` | заголовок страны от обратного прокси; пусто — не читается |
| `oshub.geo.source_order` | `база-прокси` | порядок источников; второе значение — `прокси-база` |
| `oshub.geo.update.enabled` | `Ложь` | ходить ли за выпуском базы наружу |
| `oshub.geo.update.url` | выпуск DB-IP | шаблон адреса выпуска с `{ГОД}` и `{МЕСЯЦ}` |
| `oshub.jobs.geo_update_interval_sec` | `86400` | интервал захода обновления после стартового (минимум 60) |

Все ключи — класса `bootstrap`: меняются конфигурацией и рестартом.

## Где что лежит

| Каталог | Что внутри |
| --- | --- |
| `Классы/определение/` | `ОпределительСтраны` — политика «неизвестно» и порядок источников; `СправочникСтран` |
| `Классы/база/` | `БазаСтран` — заказ и опубликованный индекс; `ОбновлениеБазыСтран` — скачать, проверить, подменить, доложить происшествием; фоновая перестройка индекса, задача обновления, коды происшествий и ключи настроек |
| `Классы/страна/` | индекс диапазонов, ключ адреса, разбор и проверка файла базы, файл с подменой, коды ISO; о хабе не знает — только библиотека `ip` и платформа, создаётся «Новым» |

## Инварианты

- Порядок политики один: «своя сеть» и не-адрес — «неизвестна» до базы; дальше источники по `oshub.geo.source_order`; ответил первый, которому есть что сказать.
- Индекс строится в фоне и публикуется подменой ссылки; пока строится новый, хаб отвечает по прежнему; сорвавшаяся сборка прежний не трогает.
- В памяти только наблюдаемые страны; пока правила не назвали ни одной, файл базы не открывается.
- Кандидат обновления проверяется до подмены; тело ответа и распакованное больше 200 МБ отвергаются, обещанный размер gzip — до распаковки.
- Модуль говорит исход и причину и ничего не закрывает; доверие заголовку решает шов входа.
