# Гео

Из какой страны пришёл запрос. Хаб отвечает на это сам, встроенной базой диапазонов
адресов, и в момент запроса никуда не ходит. Что делать с ответом, модуль не решает:
он отдаёт исход, код страны и причину словами, а правила по стране живут снаружи.

| Класс | Что делает | Знает ли о хабе |
| --- | --- | --- |
| `ОпределительСтраны` | политика «неизвестно», порядок источников, три исхода | да — желудь |
| `БазаСтран` | наблюдаемые страны, опубликованный индекс, отпечаток и возраст файла | да — желудь |
| `ОбновлениеБазыСтран` | скачать выпуск, проверить, подменить, доложить происшествием | да — желудь |
| `ПерестройкаИндексаСтран` | работа фонового задания: пересборка вне потока запроса | да |
| `СправочникСтран` | одна дверь к кодам стран для всего хаба | да — желудь |
| `страна/КодыСтран` | ISO 3166-1 alpha-2: канон, проверка, список | **нет** |
| `страна/ПорядокАдресов` | адрес → сравнимый ключ (пара 64-битных половин) | **нет** |
| `страна/ИндексСтран` | параллельные массивы на семейство плюс двоичный поиск | **нет** |
| `страна/СборкаИндексаСтран` | индекс по CSV базы с дешёвым отбором строк | **нет** |
| `страна/ПроверкаБазыСтран` | годен ли файл быть базой | **нет** |
| `страна/ФайлБазыСтран` | путь, отпечаток, подмена tmp → rename | **нет** |

## Граница `страна/`

Подкаталог `Классы/страна` не знает ни одного типа хаба: только библиотека `ip`
и примитивы платформы. Ни `КанонIP`, ни `СвояСеть`, ни настройки сюда не заходят —
всё, что зависит от хаба, живёт уровнем выше и приходит значениями. Аннотаций ОСени
здесь тоже нет: классы создаются оператором `Новый`, и вынести подкаталог
в библиотеку-сателлит можно переносом файлов, ничего в них не правя.

## Как этим пользоваться

```bsl
// правила объявляют, какие страны им нужны; под них и строится индекс
Определитель.НаблюдатьСтраны(Страны);            // Массив из Строка

// страна одного запроса — три различимых исхода
Вердикт = Определитель.ОпределитьПоЗапросу(Запрос.АдресУдаленногоУзла, Запрос.Заголовки);
Если Вердикт.Исход = Определитель.Исходы().Известна Тогда
	// Вердикт.Страна — код, Вердикт.Источник — «база» либо «прокси»
ИначеЕсли Вердикт.Исход = Определитель.Исходы().НеНаблюдаемая Тогда
	// адрес публичный, но ни в один диапазон наблюдаемых стран не попал
Иначе
	// Вердикт.Причина — почему страна неизвестна, словами
КонецЕсли;

// возраст базы и что с ней вообще
Определитель.СостояниеБазы();   // Есть, Дата, ВозрастСек, Устарела, Страны, Заказано, Строится, …

// проверка введённого администратором — отдельная дверь: за двумя буквами кода
// не приходится тянуть ни базу, ни фоновую перестройку индекса
Справочник.ЭтоКод("ru");                         // Истина
Справочник.Канон("ru");                          // «RU»
```

**Порядок политики «неизвестно» один, и второй копии его нет.** Он такой:

1. «своя сеть» судится **до** базы (`сеть/СвояСеть`): петля, частные сети, link-local, ULA,
   CGNAT и непригодные для интернета диапазоны — это «адрес не публичный». Порядок здесь
   не вкусовой: база относит служебные диапазоны IPv6 к настоящим странам, и в выпуске
   2026-09 таких дыр **десять** (таблица ниже) — спроси хаб сначала базу, петлевой сосед
   получил бы швейцарское гражданство;
2. адрес, который адресом не является, — «страна неизвестна»;
3. источники по порядку `oshub.geo.source_order`: встроенная база и заголовок доверенного
   прокси. Первый, которому есть что сказать, и отвечает; не ответивший уступает следующему;
4. индекса нет вовсе — «страна неизвестна»;
5. индекс есть, а адрес не попал ни в один диапазон — «не из наблюдаемых».

**Порядок источников — это приоритет, а не очередь из «попробуем и того и этого».** Ответ
базы «адрес публичный, но не из наблюдаемых стран» — это ОТВЕТ, а не молчание. Поэтому при
`база-прокси` (умолчание) заголовок доверенного прокси спрашивают только тогда, когда базе
сказать нечего: файла базы нет, индекс ни разу не построен, правила не назвали ни одной
страны. Инсталляции за Cloudflare, которая хочет, чтобы решал `CF-IPCountry`, а база служила
запасом, нужен `прокси-база` — иначе заголовок почти всегда останется непрочитанным.

**Пока строится новый индекс, хаб отвечает по прежнему.** Правила назвали другие страны —
заказ виден сразу (`СостояниеБазы().Заказано`, `.Строится`), а действовать он начинает
с публикацией нового индекса, через секунды. Иначе каждая правка списка стран на всё время
сборки закрывала бы вход посетителям планеты. «Страна неизвестна» из-за перестройки бывает
ровно один раз — на первом построении, когда прежнего индекса ещё нет. Сорвавшаяся сборка
прежний индекс не трогает вовсе: причина видна в `СостояниеБазы().Помеха`, а следующий заход
задачи пробует снова.

**Источники отвечают по-разному, и это честно.** База знает только наблюдаемые страны,
поэтому про чужой адрес она говорит «не из наблюдаемых» — она и вправду не знает.
Заголовок доверенного прокси приносит код целиком, поэтому «DE» от него — это
`известна(DE)`, а не «не из наблюдаемых».

## База

Источник — **DB-IP Lite Country** (CC BY 4.0, без учётной записи): CSV без заголовка,
три колонки `первый адрес,последний адрес,код страны`, IPv4 и IPv6 в одном файле, около
717 тысяч строк и 30 МБ в распакованном виде. Атрибуция обязательна: `IP Geolocation by DB-IP`
со ссылкой на `https://db-ip.com` — её ставят страницы, которые пользуются результатом
(см. ИСТ-ДОСТ-037).

В памяти лежат **только наблюдаемые страны**, а не вся база мира: одна Россия — это
15,7 тысячи диапазонов из 717 тысяч строк. Строки отбираются по хвосту `,RU` **до** разбора,
потому что 717 тысяч вызовов `СтрРазделить` стоят дороже всей остальной сборки.
Замеры на файле 2026-09:

| Наблюдаемые страны | Диапазонов | Сборка | Индекс в памяти | На пике перестройки |
| --- | --- | --- | --- | --- |
| RU | 15 676 | ≈ 2,5 с | ≈ 31 МБ | ≈ 62 МБ |
| RU, BY, KZ, DE, US | 145 068 | ≈ 15 с | ≈ 345 МБ | **≈ 666 МБ** |

Диапазон стоит около двух килобайт: две структуры-ключа по три поля каждая плюс код страны.
На пике памяти живут **два** индекса разом — прежний, по которому хаб продолжает отвечать,
и собираемый новый. Поэтому индекс строится **в фоне**: старт хаба он
не держит, а пока он строится, страна считается неизвестной.

**Служебные диапазоны IPv6, которые база отдаёт странам** (выпуск 2026-09). Все, кроме
последнего, закрыты списком `сеть/СвояСеть` — он судится раньше базы:

| Диапазон | Что это | Кому отдан | Чем закрыт |
| --- | --- | --- | --- |
| `2001::/32` | Teredo | US | `2001::/23` — назначения протоколов IETF |
| `2001:1::/32` | протокольные присвоения | CH | то же |
| `2001:2::/48` | испытательный стенд | US | то же |
| `2001:3::/32` | AMT | US | то же |
| `2001:10::/28` | ORCHID | US | то же |
| `2001:20::/28` | ORCHIDv2 | US | то же |
| `2001:30::/28` | удалённая идентификация | CH | то же |
| `3fff::/20` | документация (RFC 9637) | CH | `3fff::/20` |
| `5f00::/16` | идентификаторы сегментов SRv6 (RFC 9602) | CH | `5f00::/16` |
| `fe00::/9` | зарезервировано IETF | CH | `fe00::/9` |
| `fec0::/10` | site-local, отменён RFC 3879 | CH | `fec0::/10` |
| `ff00::/8` | групповые адреса | CH | `ff00::/8` |
| `fc00::/7`, `fe80::/10`, `::/8` | ULA, link-local, нижняя часть | ZZ | «ZZ» не страна, плюс `сеть/СвояСеть` |
| **`2002::/16`** | **6to4** | **US** | ⚠ **не закрыт** — внутри адрес IPv4, судить надо развернув; долг НФТ-ДОСТ-013 |

`2001::/23` — это блок IANA целиком, пользовательского пространства в нём нет: адреса
регистраторов начинаются с `2001:200::`. `2001:db8::/32` в него не входит и закрыт отдельной
строкой, как и раньше.

**Обновление из сети по умолчанию выключено** (`oshub.geo.update.enabled = Ложь`):
закрытый контур наружу не ходит, файл туда кладут руками по названному пути. Хаб замечает
новый файл по отпечатку (размер плюс время изменения) на тике задачи `job.geo_update`
и перечитывает его сам. Включённое обновление скачивает выпуск текущего месяца, а если
его ещё нет — прошлого, распаковывает gzip библиотекой `compressor`, проверяет кандидата
и только потом подменяет базу.

## Настройки

| Ключ | Умолчание | Что значит |
| --- | --- | --- |
| `oshub.geo.db_path` | пусто | путь к файлу базы; пусто — `<oshub.storage.root>/гео/dbip-country-lite.csv` |
| `oshub.geo.header` | `CF-IPCountry` | заголовок страны от обратного прокси; пусто — не читать вовсе |
| `oshub.geo.source_order` | `база-прокси` | порядок источников; второе значение — `прокси-база` |
| `oshub.geo.update.enabled` | `Ложь` | ходить ли за базой наружу |
| `oshub.geo.update.url` | адрес DB-IP | шаблон выпуска с `{ГОД}` и `{МЕСЯЦ}` |
| `oshub.jobs.geo_update_interval_sec` | `86400` | как часто идёт заход обновления (минимум 60) |

## Что осталось за пределами модуля и почему

- **доверие заголовку** решается там, где известен адрес СОЕДИНЕНИЯ, — на шве входа
  (`вход/на-входе/ДовериеЗаголовкуСтраны` под обёрткой `ОбработчикСоСтранойОтПрокси`). К моменту,
  когда до заголовка доберётся определитель, адрес запроса уже переписан адресом человека,
  и судить доверие по нему нельзя;
- **«своя сеть»** — это `сеть/СвояСеть`, один список на хаб. Копии его здесь нет;
- **канон адреса** — `основа/КанонIP`: отображённый IPv4 разворачивается там же, где
  и для всего остального хаба;
- **правила по стране** (кому и что закрывать) модуль не знает вовсе — они снаружи,
  и они же говорят определителю, какие страны наблюдать;
- **экраны** базы не здесь: модуль отдаёт `СостояниеБазы`, разметку печатает `интерфейс`.

## Мины этого слоя

- **Индекс публикуется подменой ссылки, а не правкой на месте.** Его читают потоки
  запросов, и структурная правка массива из потока сборки рвёт читающему коллекцию.
  Новый набор стран — новый индекс; поле присваивается целиком и последним.
- **Пока страны не названы, файл не открывается вовсе.** `БазаСтран.ПрочтенийФайла()`
  так и остаётся нулём: запрос, которому страна не нужна, за неё не платит ничем.
- **База раздаёт странам десять служебных диапазонов IPv6.** В выпуске 2026-09 это семь
  назначений протоколов IETF (`2001::/23` целиком — Teredo, протокольные присвоения,
  испытательный стенд, AMT, ORCHID обеих версий, удалённая идентификация; то США, то
  Швейцария), документационный `3fff::/20`, `5f00::/16` и хвост — `fe00::/9` с `fec0::/10`.
  Чинить базу не за чем: все десять закрыты списком `сеть/СвояСеть`, который судится раньше,
  и до индекса такие адреса не доходят. Открытым остаётся один — 6to4 `2002::/16` (база
  отдаёт его США): он несёт внутри себя адрес IPv4, и судить его надо развернув, а не
  префиксом; это долг НФТ-ДОСТ-013.
- **«XK» в справочнике кодов — не опечатка.** Стандарт ISO 3166 кода XK не назначает; так
  Косово зовут DB-IP и большинство геобаз, и без него диапазоны Косова наблюдать нечем.
- **Скачивание выпуска сеть НЕ судит** — как и остальные источники хаба (решение владельца,
  НФТ-ДОСТ-013): адрес выпуска это ключ `bootstrap`, его пишет тот, кто разворачивает.
  Зато есть потолок: и тело ответа, и распакованное больше 200 МБ отвергаются, причём
  обещанный размер читается из хвоста gzip ДО распаковки — у архивной бомбы тело маленькое.
- **Память — два килобайта на диапазон, и на пике индексов два.** Пять стран — это две
  трети гигабайта на время перестройки (таблица замеров выше); контейнеру с жёстким лимитом
  памяти столько наблюдаемых стран не по карману. Дешёвая оптимизация на будущее известна
  и намеренно не сделана: шесть плоских массивов чисел вместо двух массивов структур-ключей
  убирают объект на каждую границу диапазона.
- **Ключ адреса — пара 64-битных половин, а не одно число.** 2^128 в десятичном `Число`
  OneScript не помещается, 2^64 помещается точно. Строки в качестве ключа не годятся вовсе:
  `1.9.0.0` лексикографически больше `1.10.0.0`.
- **Кандидат судится до подмены.** Оборванная закачка и страница ошибки чужого сервера
  выглядят файлом ровно так же, как база; подмена идёт tmp → rename, а прежняя база
  уезжает в сторону и удаляется только после удачной подмены.
