# Контракт службы «Пульт журнала»

Единственная точка встречи движка и экрана. Экран знает только этот желудь; движок не знает
об экране. Менять контракт может только управляющий: нужна правка — автор трека пишет её
в свой отчёт разделом «Правка контракта» и сообщает управляющему, сам соседний трек не трогает.

Желудь `ПультЖурнала`, модуль `src/модули/наблюдаемость/Классы/журнал/`.

## Уровни

`DEBUG`, `INFO`, `WARN`, `ERROR`, `CRITICALERROR`, `DISABLE` — строками, в этом порядке
от подробного к молчаливому. `Уровни()` отдаёт этот перечень массивом.

## Узел — описание одного лога

`Логи()` отдаёт массив узлов, `Корень()` — узел корневого лога. Метод ничего не меняет.

| Поле | Тип | Смысл |
| --- | --- | --- |
| `Имя` | Строка | имя лога; у корня — `rootLogger` |
| `Группа` | Строка | путь через «/»: `хаб/<модуль>[/<раздел>]`, `хаб/oshub`, `библиотеки/<библиотека>`; у корня пусто |
| `УровеньПриСтарте` | Строка | уровень, с которым лог живёт по настройкам: свой либо корневой |
| `СвойПриСтарте` | Булево | Истина — настройка назвала уровень именно этому логу |
| `ОткудаПриСтарте` | Строка | `окружение`, `файл`, `умолчание` |
| `ИмяНастройки` | Строка | что показать оператору: имя переменной либо ключа, которым задан уровень при старте; пусто при умолчании |
| `УровеньСЭкрана` | Строка или Неопределено | уровень, заданный с экрана и действующий сейчас |
| `ЗаданоКем` | Строка или Неопределено | логин того, кто задал уровень с экрана |
| `ЗаданоКогда` | Дата (UTC) или Неопределено | когда задал |
| `УровеньДействующий` | Строка | с каким уровнем лог пишет прямо сейчас |
| `ВКонсоль` | Булево | строки лога идут в консоль |
| `ВПамять` | Булево | строки лога идут в память для просмотра на экране |
| `ВOTel` | Булево | строки лога идут в коллектор (при включённой телеметрии) |
| `ПорогOTel` | Строка или Неопределено | ЗАДАННЫЙ логу порог коллектора (настройкой либо с экрана): «в коллектор только с этого уровня». Назван и тогда, когда сейчас ничего не сужает (порог не подробнее уровня лога). Неопределено — порога нет, коллектор следует уровню лога |
| `OTelСЭкрана` | Булево | отправка в коллектор изменена с экрана |
| `OTelЗаданКем`, `OTelЗаданКогда` | как выше | кто и когда изменил отправку |
| `МожноВOTel` | Булево | Ложь — лог до коллектора не доходит вовсе (взят у logos мимо контейнера); флаг у такого лога не правится |
| `ТолькоЧтение` | Булево | Истина — пульт этот лог не правит |
| `ПочемуТолькоЧтение` | Строка | код причины: `audit` — журнал аудита; `before_wiring` — лог создан раньше, чем хаб прочитал настройки, и пишет мимо двери обезличивания; пусто, если лог правится. Слова — в словаре экрана |
| `ПрочиеВыходы` | Массив из Строка | чужие способы вывода лога (файл аудита); показываются без правки |
| `СтрокЗаМинуту` | Число | сколько строк лог написал за последнюю минуту |

## Правки

Все правки действуют сразу и живут до перезапуска процесса. `Кто` — логин администратора,
`АдресIP` — адрес клиента для журнала аудита (необязательный, по умолчанию пусто) — как у
`СервисНастроек`. Каждая правка пишется в журнал аудита.

**Что правкой не считается** (уточнено 2026-09-28 по ревью пульта, З-4): только повтор СВОЕГО
состояния лога. Свой уровень лога — заданный с экрана, а если с экрана не задан — названный этому
логу (или предку по имени) настройкой при старте. Уровень, который лог получает от корня, своим не
считается: явная правка того же значения — правка, она закрепляет уровень за логом и пишется
в аудит; после возврата корня лог пишет выбранным уровнем. То же для отправки в коллектор:
повтор — только совпадение со своим состоянием отправки лога.

**Что возвращает правка.** Все четыре метода правок возвращают `Структура`: `Применено` (Массив из
Строка — логи, у которых состояние изменилось) и `Пропущено` (Массив из Строка — логи только для
чтения, которых правка не коснулась). Повторы не попадают ни туда, ни туда. Экран сообщает оператору
ровно это, а не свой расчёт.

| Метод | Что делает |
| --- | --- |
| `ЗадатьУровень(ИменаЛогов, Уровень, Кто, АдресIP = "")` | задаёт уровень каждому логу из массива имён; ветка, путь и «всем под отбором» — это тот же вызов со списком имён |
| `ЗадатьУровеньКорню(Уровень, Кто, АдресIP = "")` | задаёт уровень корню; его получают логи без своего уровня |

**Корень — лог с именем `rootLogger`.** Все методы, принимающие `ИменаЛогов`, принимают и это имя:
`ВернутьКСтарту(["rootLogger"], Кто)` возвращает корень, `ОтправлятьВOTel(["rootLogger"], …)` правит
отправку корня. `ЗадатьУровеньКорню` — то же, что `ЗадатьУровень(["rootLogger"], …)`.

Продолжение таблицы правок:

| Метод | Что делает |
| --- | --- |
| `ОтправлятьВOTel(ИменаЛогов, Признак, Кто, АдресIP = "", Порог = "")` | включает и выключает отправку в коллектор; порог только сужает: ниже уровня лога подробности не добавляет |
| `ВернутьКСтарту(ИменаЛогов, Кто, АдресIP = "")` | снимает заданное с экрана (уровень и отправку) у названных логов |

**Список, в котором нечего править.** Если в списке имён нет ни одного лога, который можно
править (все только для чтения), правка отвергается `log.read_only` и в аудит не пишется. Если
такие логи есть в списке вперемешку с правимыми — они попадают в `Пропущено`, остальные правятся.
Пустой список имён — не правка: `Применено` и `Пропущено` пусты, аудита нет.

Отказы — исключением с кодом в начале текста: `log.unknown_level`, `log.unknown_logger`,
`log.read_only`, `log.otel_unreachable` (правка отправки у лога с `МожноВOTel = Ложь`).

## Пути

`Пути()` → массив структур `Ключ` (Строка) и `Логи` (Массив из Строка). Путь — перечень логов,
участвующих в одном деле оператора. Закрытый список ключей: `delivery` (выдача пакета),
`upstream` (поход к чужому хабу), `intake` (приём внешней версии), `publish` (публикация),
`login` (вход), `notifications` (очередь уведомлений), `storage` (хранилище артефактов).
Состав пути — знание устройства хаба, живёт в движке. Подписи путей — в словаре экрана.

## Строки

`Хвост(Отбор)` → массив записей, свежие первыми.

Запись: `Номер` (Число, растёт всю жизнь процесса), `Время` (Дата UTC), `Миллисекунды` (Число),
`Уровень` (Строка), `Лог` (Строка), `Текст` (Строка — уже после двери обезличивания, ровно то,
что ушло в консоль), `Трасса` (Строка — trace_id либо пусто).

Отбор (Структура, любое поле можно не задавать): `Логи` (Массив из Строка), `Группа` (Строка —
начало пути группы), `УровеньНеНиже` (Строка), `Содержит` (Строка), `После` (Число — только
записи с номером больше), `Количество` (Число, умолчание 200), `ТолькоВажное` (Булево — читать
кольцо предупреждений и ошибок, которое отладка не вытесняет).

`СчётПамяти()` → Структура `Всего` (записано за жизнь процесса), `Ёмкость`, `ЁмкостьВажного`.

## Сведения

| Метод | Что отдаёт |
| --- | --- |
| `ЖурналУходитВКоллектор()` | Булево: телеметрия включена и экспортёр логов не выключен |
| `СтрокиДляЗакрепления()` | Массив из Строка — готовые строки переменных окружения, закрепляющие заданное с экрана (`OSHUB_LOG_LEVELS=…`, `OSHUB_LOG_OTEL_LEVELS=…`); пусто, если с экрана ничего не задано |

## Инварианты

- В коллектор никогда не уходит строка подробнее действующего уровня лога и подробнее заданного
  порога: при смене уровня лога на лету пульт приводит уровень выхода коллектора.
- `Хвост` с уровнем не из перечня в отборе не отказывает: такой отбор уровень не сужает.
- `СвойПриСтарте` — Истина, если настройка назвала уровень этому логу либо его предку по имени.
- Имя корня `rootLogger`, ряд уровней и правило «сужает ли порог» живут в одном месте кода;
  связка, пульт и память берут их оттуда.
- Выключенная настройкой отправка (`OSHUB_LOG_OTEL_LEVELS=<лог>=DISABLE`) и выключенная с экрана —
  одно и то же состояние: выход коллектора у лога есть, пишет с уровнем `DISABLE`, тумблер можно
  включить. `МожноВOTel = Ложь` — только у лога, до которого коллектор не доходит вовсе.
- Хаб, поднятый со строками `СтрокиДляЗакрепления()`, стартует с тем же состоянием логов (уровень,
  `ВOTel`, `МожноВOTel`, порог), какое было задано с экрана.

## Чего в контракте нет намеренно

- Яруса наследования «ветка»: у logos нет наследования на лету, ветка — групповая правка.
- Хранения правок в базе: правка с экрана — оперативное действие, а не настройка.
- Срока действия правки: вопрос вынесен владельцу.

`ВернутьВсёКСтарту` снят 2026-09-28: экран снимает ровно показанное оператору через `ВернутьКСтарту(<показанные имена>)`, у метода не осталось потребителей.
